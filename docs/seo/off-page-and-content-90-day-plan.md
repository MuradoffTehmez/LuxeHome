# Luxe Home Estate — 90 günlük off-page və content planı

Bu plan yalnız təsdiqlənmiş biznes məlumatları və real müştəri münasibətləri ilə icra olunur. Reytinq, rəy, satış sayı, tərəfdaşlıq və media qeydini sübut olmadan yaratmaq olmaz. Bütün platformalarda əsas NAP mənbəyi `src/config/site.ts`-dir; ünvan ziddiyyəti həll edilənədək yeni kataloq təqdimatı dayandırılır.

## 0–30 gün — baza və etibar

- Google Business Profile sahiblik və girişini təsdiqlə; biznes adı kimi yalnız hüquqi/ictimai brend adını istifadə et.
- Əsas kateqoriyanı faktiki fəaliyyətə uyğun seç, əlavə kateqoriyaları yalnız göstərilən xidmətlər olduqda əlavə et. Açar sözləri biznes adına doldurma.
- Ünvanı 109A/45A qərarından sonra sayt, GBP, Maps və bütün kataloqlarda eyniləşdir. Telefon, e-poçt və canonical domen də eyni NAP auditinə daxil olsun.
- Dəqiq pin, xidmət ərazisi və iş saatlarını şirkətdən yazılı təsdiq alındıqdan sonra daxil et.
- Real ofis, komanda, fasad və iş prosesi fotoları üçün çəkiliş siyahısı hazırla; metadata/alt mətn yalnız fotoda görünəni təsvir etsin.
- Həftədə bir real GBP postu yayımla: yeni elan, xidmət izahı və ya faydalı Bakı əmlak məsləhəti. Qiymət və status dəyişəndə postu yenilə/sil.
- Əməliyyatdan sonra neytral rəy sorğusu qur. Müsbət rəyə görə mükafat, rəy seçimi, işçi/saxta hesab və hazır mətn qadağandır.
- GSC-də domen property-ni, sitemap təqdimatını, index coverage və page indexing baseline-ını qeyd et.
- Prioritet rayon və metro siyahısını real inventar və biznes prioritetinə görə təsdiqlə; 3 aktiv elandan az olan landing indekslənməsin.

## 31–60 gün — yerli sitatlar və mövzu klasterləri

- Etibarlı yerli biznes kataloqları, peşə assosiasiyaları və xəritə xidmətləri üçün keyfiyyət siyahısı yarat. Hər təqdimatdan əvvəl domenin indekslənməsi, spam səviyyəsi və redaksiya qaydasını yoxla.
- Kataloq təqdimatlarını eyni NAP, canonical URL və təbii təsvirlə et; kütləvi aşağı keyfiyyətli paketlərdən istifadə etmə.
- Real hüquqşünas, ipoteka mütəxəssisi, təmir şirkəti, fotoqraf və yaşayış kompleksi tərəfdaşları ilə faydalı ortaq material planla. Link ödəniş qarşılığıdırsa bunu uyğun atribut və açıqlama ilə işarələ.
- İlk content klasterlərini qur: Bakı mənzil alışı, kirayə prosesi, sənəd yoxlaması, ipoteka hazırlığı və rayon müqayisəsi. Hər məqalə real müəllif, tarix, mənbə və uyğun landing/detail daxili linki alsın.
- Rayon/metro yazılarında yalnız doğrulanmış nəqliyyat, infrastruktur və inventar məlumatı istifadə et; ümumi marketinq klişesi ilə “ən yaxşı” iddiası yaratma.
- GBP-də həftəlik foto/post ritmini saxla, suallara və bütün real rəylərə faktiki, məxfi məlumat paylaşmadan cavab ver.
- GSC query/page məlumatında yüksək impression, aşağı CTR səhifələrini seç; title/description dəyişikliklərini tarix və əvvəlki variantla qeyd et.

## 61–90 gün — nüfuz, PR və optimallaşdırma

- Yerli media və ekspert platformaları üçün data-backed mövzular hazırla: açıq mənbələrə əsaslanan bazar izahı, sənəd təhlükəsizliyi və istehlakçı bələdçisi. “Bazar lideri” kimi sübutsuz iddialar etmə.
- Tərəfdaş materiallarının indeks, referral və lead keyfiyyətini ölç; yalnız real trafik və reputasiya dəyəri verən əlaqələri davam etdir.
- Content klasterlərini GSC query boşluqları ilə genişləndir, zəif/üst-üstə düşən materialları birləşdir və canonical/daxili linkləri yenilə.
- Etik rəy axınında sorğu sayı, cavab faizi və cavab müddətini ölç; rəy məzmununa və reytinqə müdaxilə etmə.
- GBP Insights, GSC və consent-li GA4 nəticələrini aylıq hesabatda birləşdir: branded/non-branded visibility, indexed pages, CTR, organic landing engagement və PII-siz conversion eventləri.
- 90-cı gün texniki audit, NAP audit, backlink keyfiyyət yoxlaması və növbəti rüb prioritetləşdirməsi apar.

## Həftəlik idarəetmə ritmi

| Ritm | İş | Sübut |
| --- | --- | --- |
| Həftəlik | GBP post/foto, rəylərə cavab, yeni 404 və GSC anomaliyası | URL, screenshot, tarix |
| İki həftədən bir | Yeni content və daxili link review-u | publish URL, müəllif, mənbələr |
| Aylıq | NAP, index, schema, CWV və backlink audit | ölçmə runbook-u üzrə hesabat |
| Rüblük | Landing inventarı və 3-elan keyfiyyət qapısı | DB/audit export-u |

## Uğur meyarları

Baseline ölçülmədən faiz hədəfi qoyulmur. İlk ay baseline dondurulur; sonrakı qərarlar GSC impressions/clicks/CTR, index coverage, GBP görünürlüyü, real referral domenləri və consent-li conversion eventlərində trend ilə verilir.
