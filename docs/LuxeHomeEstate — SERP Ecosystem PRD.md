# 1. Executive Summary

LuxeHomeEstate üçün məqsəd sadəcə klassik SEO optimizasiyası etmək deyil.

Məqsəd vahid **SERP Ecosystem** qurmaqdır.

Bu sistem LuxeHomeEstate-in aşağıdakı kanallarda paralel görünməsini təmin etməlidir:

- Google organic search;
- Google Images;
- Google Maps / Local Pack;
- brand/entity nəticələri;
- agent və agentlik nəticələri;
- property listing nəticələri;
- informational search;
- long-tail search;
- featured answer formatları;
- AI əsaslı axtarış sistemləri;
- generativ AI cavablarında mənbə kimi göstərilmə;
- Bing və digər axtarış sistemləri;
- gələcəkdə digər discovery platformaları.

Sistem aşağıdakı istiqamətləri vahid arxitektura daxilində birləşdirməlidir:

- Technical SEO
- On-page SEO
- Programmatic SEO
- Local SEO
- Entity SEO
- Image SEO
- Content SEO
- AEO — Answer Engine Optimization
- GEO — Generative Engine Optimization
- Structured Data

Əsas prinsip:

> LuxeHomeEstate yalnız bir URL-in Google-da sıralanmasına deyil, müəyyən daşınmaz əmlak mövzusu üzrə bütün SERP səthlərində maksimum görünürlük əldə etməyə çalışmalıdır.

# 7. URL Architecture

URL strukturu deterministic və SEO-friendly olmalıdır.

Əsas locale strukturu:

```text
/az/
/en/
/ru/
```

Azərbaycan üçün:

```text
/az/emlaklar
/az/satilan-emlaklar
/az/kiraye-emlaklar
/az/bakida-satilan-menziller
/az/bakida-kiraye-menziller
```

Rayon səviyyəsi:

```text
/az/yasamalda-satilan-menziller
/az/nerimanovda-satilan-menziller
/az/xetaide-satilan-menziller
```

Əmlak detail:

```text
/az/emlaklar/{seo-slug}
```

Agent:

```text
/az/agentler/{agent-slug}
```

Agency:

```text
/az/agentlikler/{agency-slug}
```

Knowledge Hub:

```text
/az/bloq/{slug}
```

və ya gələcəkdə:

```text
/az/bilik-merkezi/{slug}
```

# 8. URL Rules

URL:

- lowercase olmalıdır;
- Unicode və ya transliteration strategiyası vahid olmalıdır;
- lazımsız ID URL-də göstərilməməlidir;
- slug dəyişdikdə redirect yaradılmalıdır;
- eyni content bir neçə URL-dən açılmamalıdır;
- trailing slash siyasəti bütün sistemdə eyni olmalıdır;
- `www` və non-www paralel indekslənməməlidir.

Canonical host:

```text
https://luxehomeestate.az
```

olmalıdır.

---

# 9. Root Locale Strategy

Root:

```text
https://luxehomeestate.az/
```

əsas bazara uyğun davranmalıdır.

Tövsiyə edilən əsas locale:

```text
/az
```

Root üçün istifadəçinin browser dilinə görə SEO baxımından qeyri-sabit redirect yaradılmamalıdır.

Əsas canonical locale Azərbaycan dili olmalıdır.

# 10. Multilingual SEO

Hər indekslənə bilən səhifənin dil variantı olduqda `hreflang` yaradılmalıdır.

Nümunə:

```html
<link rel="alternate" hreflang="az"
href="https://luxehomeestate.az/az/..." />

<link rel="alternate" hreflang="en"
href="https://luxehomeestate.az/en/..." />

<link rel="alternate" hreflang="ru"
href="https://luxehomeestate.az/ru/..." />

<link rel="alternate" hreflang="x-default"
href="https://luxehomeestate.az/az/..." />
```

Qaydalar:

- hər locale özünə canonical verməlidir;
- AZ səhifəsi EN səhifəsinə canonical olmamalıdır;
- hreflang bidirectional olmalıdır;
- mövcud olmayan translation üçün saxta URL yaradılmamalıdır;
- avtomatik maşın tərcüməsi keyfiyyətsizdirsə index edilməməlidir.

# 21. Property Validation Engine

Listing publish olunmazdan əvvəl validator işləməlidir.

Minimum checks:

```text
rooms > 0
area > 0
price > 0
city != null
propertyType != null
transactionType != null
images >= minimum
title != null
description != null
```

Əlavə logical validation:

```text

district city ilə uyğun
```
